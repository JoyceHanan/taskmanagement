
# Task Management System

## Features
- User Authentication
- JWT Authorization
- Role-Based Access
- Task CRUD Operations
- Admin Dashboard

## Tech Stack
- React
- Node.js
- Express
- MongoDB

## Installation

### Backend
npm install
npm run dev

### Frontend
npm install
npm run dev

## Environment Variables

MONGO_URI=
JWT_SECRET=
JWT_REFRESH=

## API Routes

POST /user-api/register
POST /user-api/login
GET /task-api/tasks
POST /task-api/tasks

## Scalability Notes
- Modular backend architecture
- JWT stateless authentication
- Separate admin/user APIs
- Easily extensible for microservices
